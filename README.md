Esse é o repositório do meu portfólio pessoal! Este projeto foi desenvolvido para mostrar um pouco mais sobre mim, habilidades técnicas, formação acadêmica e os projetos que desenvolvi como Desenvolvedor Web (Foco em Backend e Full Stack).

## 🚀 Deploy e Hospedagem

O projeto está hospedado utilizando o **GitHub Pages**, permitindo acesso rápido e direto através do navegador.

🔗 **Link para acesso:** https://gabrielfilomeno.github.io/portfolio/

---

## 💻 Sobre o Projeto

Este é um site estático desenvolvido "do zero", sem o uso de frameworks. A ideia é ser simples e direto com a base do desenvolvimento web (`HTML`, `CSS` e `JavaScript`). O design foi pensado no `Mobile First` e utiliza um tema escuro (Dark Mode), transmitindo uma identidade visual moderna e tecnológica.

---

## ✨ Funcionalidades

- **Design Responsivo:** Layout adaptável para desktops, tablets e dispositivos móveis (Mobile First).
- **Menu de Navegação Dinâmico:**
  - Menu "Hambúrguer" animado para versões mobile.
  - **Scroll Spy:** O menu destaca automaticamente a seção que está visível na tela enquanto o usuário rola a página.
  - Navegação suave (Smooth Scroll) ao clicar nos links.
- **Acessibilidade:**
  - Uso de tags semânticas HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`).
  - Atributos ARIA (`aria-label`, `aria-expanded`, `aria-current`) para leitores de tela.
  - Foco gerenciável para navegação via teclado.
- **Interatividade:**
  - Efeitos de _Hover_ em botões, links e cards.
  - Cards de projetos inteiramente clicáveis (Stretched Link).

---

## 🛠 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:**
  - **Variáveis CSS (`:root`)**: Para fácil manutenção da paleta de cores e fontes.
  - **Flexbox & Grid**: Para layout e alinhamento dos elementos.
  - **Media Queries**: Para responsividade.
- **JavaScript (ES6+):** Lógica do menu mobile e detecção de scroll (Scroll Spy).
- **Font Awesome:** Ícones para redes sociais e contatos.
- **Google Fonts:** Tipografia (Roboto e Poppins).

## ⚡ Como Executar Localmente

Para rodar este projeto na sua máquina, você não precisa de nenhuma instalação complexa, apenas um navegador web.

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/GabrielFilomeno/portfolio.git
    ```
2.  **Abra o arquivo:**
    - Dê um duplo clique no arquivo `index.html`.
    - Ou, se usar o VS Code, instale a extensão "Live Server" e clique em "Go Live".
